# 写真現像ラボ ／ スライドショー工房

写真講習用の2つのアプリです。どちらもブラウザだけで動き、写真や動画はどこにも送信されません（すべて端末の中で処理します）。

| アプリ | 場所 | できること |
|---|---|---|
| 写真現像ラボ | このフォルダの直下 | JPEGとRAWの現像。明るさ・色・トーンカーブ・効果・部分補正・切り抜きと構図を、解説を見ながら練習。保存時に額縁・署名・撮影情報・SNSの形・プリントサイズなどの仕上げ |
| スライドショー工房 | `slideshow/` | 写真を選ぶだけで、音楽つきのスライドショー動画（MP4）を作成。透かしなし |

写真現像ラボの保存画面にある「スライドショーに送る」で、仕上げた写真をスライドショー工房へ渡せます（同じ端末の中だけで受け渡します）。

## 受講生の使い方

1. 講師から受け取ったリンクを **Chrome**（iPhoneは **Safari**）で開く
2. ホーム画面に追加する
   - Android（Chrome）：メニュー（︙）→「ホーム画面に追加」（写真現像ラボは画面上の「インストール」ボタンでも可）
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると、アプリとして全画面で使えます。一度開けば、電波がない所でも起動できます
4. スライドショー工房は、リンクの最後に `slideshow/` を付けたページです。こちらも同じようにホーム画面に追加できます

## 公開のしかた（GitHub Pages）

1. このリポジトリの **Settings → Pages** を開く
2. 「Build and deployment」の **Source** を「Deploy from a branch」にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 数分後、同じ画面に表示されるURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が写真現像ラボのリンクです。スライドショー工房は、その後ろに `slideshow/` を付けたURLです

ファイルを更新すると、アプリを開き直したときに新しい版に切り替わります。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 写真現像ラボ本体 |
| `raw-decoder.js` | RAW現像の部品（下の「使っている部品」を参照） |
| `manifest.webmanifest`・`sw.js`・`icons/` | ホーム画面に追加する設定、電波がない所でも起動する仕組み、アイコン |
| `slideshow/` | スライドショー工房（同じ構成のファイル一式） |

## 制限

- キヤノンのCR3は、ファイルの中の高画質JPEGで開きます（RAWのままは現像できません）
- メモリが足りない端末では、RAWを半分の大きさで現像します（その時は画面にお知らせが出ます）
- iPhoneの広い色の範囲（Display P3）の写真は、標準の色の範囲（sRGB）にして扱います
- スライドショー工房は写真だけを使います（動画クリップは使えません）。HEIC形式は、ブラウザによっては読み込めません
- 構図ページのL字構図・逆三角形構図は、参考資料で確認できなかったため一般的な説明として載せています
